# OctoAcme Project Management Docs

This folder contains OctoAcme's project management process documentation. The README provides a short overview of how we run projects and direct links to each major process document so team members and new joiners can find guidance quickly.

## Project Management Process Summary

OctoAcme follows an iterative, customer-focused approach emphasizing clear ownership, frequent communication, data-driven planning, and continuous improvement. Key process stages:

- Initiation
  - Problem framing, stakeholders, success criteria, and go/no-go decision
- Planning
  - Define scope, build and prioritize backlog, identify risks, and create release plans
- Execution & Tracking
  - Daily standups, task boards, QA/testing workflows, and progress reporting
- Risk & Communication
  - Maintain a risk register, perform regular risk reviews, and provide stakeholder updates
- Release & Deployment
  - Release checklists, deployment steps, and an incident/playbook for post-release issues
- Retrospective & Continuous Improvement
  - Regular retrospectives, action tracking, and process updates based on feedback and metrics

- Managers and project leads: follow the Initiation → Planning → Execution flow and consult the checklists for handoffs and releases.
